# MINIMAG guide assets

`screenshots/01-mp-tool-parameters.png` reproduces Figure 1 from page 9 of the supplied `minimag-guide.pdf`. It was extracted from a rendered PDF page and cropped to the application window; the figure content was not redrawn or altered.

The figure is an example, not a verified configuration for every drive. In particular, its Begin/End Serial values differ; use the written serial guidance in the guide. The trailing vendor space cannot be verified visually, and NAND/DRAM settings must match the actual hardware.

The source PDF has not been committed. Its title, scope, and editorial notes are recorded in the guide overview, with page-to-chapter coverage in the contents page.
